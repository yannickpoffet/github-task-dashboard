    Branch scan (on demand, one repo at a time)

    Only the repo chosen here is listed; earlier scans stay stored and reappear when you pick that repo again. Looks at the 300 most recently updated branches. Branches with an open PR, the default and base branches, and long-lived ones (release/*, hotfix/*, develop, protected) are skipped. "Only mine" keeps branches whose latest commit is yours. A branch is dead when its PR was merged, it has nothing ahead of the base, or (Settings) it has had no commits for N days.

    Sources: GitHub GraphQL search (open PRs involving you, review requests, issues assigned to or opened by you) and on-demand branch scans. Read-only: nothing is merged, closed or deleted. Not covered: Actions failures, Dependabot and security alerts.

    GitHub token

    Paste a classic personal access token with repo and read:org scopes, then authorize it for your organization (Configure SSO). It is stored only in this browser's localStorage and sent only to api.github.com.

    Settings

    Notifies about new items waiting on you, new comments or pushes on them, your PRs becoming ready to merge, CI turning red and your PRs closing. It only works while a tab with this page is open (it then also refreshes in the background) and only when the page is not the focused tab.
